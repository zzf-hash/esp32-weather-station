# ESP32 桌面气象站

MicroPython 桌面气象站:2.4 寸 ILI9341 彩屏(240×320),三页轮换显示时钟 / 天气 / 室内温湿度。

> 本仓库当前用途:**界面重设计**。设计师请重点读下面的「界面现状」与「硬约束」,交付物是改过的 `main.py` 页面绘制函数 / `ui.py` 配色 / 字体规格。

## 当前界面（方向二：暖色渐变卡片）

三页仍是时钟 / 天气 / 室内温湿度。绘制改为暖色渐变色带、圆角卡片、中文文案和矢量天气图标。坐标、配色、字库子集和真机校色步骤见 [`docs/设计规范-暖色卡片.md`](docs/设计规范-暖色卡片.md)。下面的「界面现状」是改版前的布局；分辨率、刷新和「内容变化才重绘」等硬约束仍然有效。

字库是 Noto Sans CJK SC 的子集（`font.py`，约 349KB，由 `makefont.py` 生成）。界面文案里要加新字时，先放进 `makefont.py` 的 `CHARSET_CN`，再重新生成 `font.py`。

真机校色用根目录的 `colortest.py`。它只临时跑在板上，不覆盖 `main.py`：

```bash
mpremote connect COM7 cp ili9341.py config.py :/ + run colortest.py
```

对照设计规范「校色」一节看色块。脚本顶部的 `SWAP_BYTES` 用来试 RGB565 字节序，`MADCTL` 用来试红蓝通道（`None` 表示沿用驱动默认 `0x48`）。

## 硬约束(设计时必读)

- **屏幕物理分辨率 240×320,RGB565(65536 色)**,不可变更
- **整屏刷新约 1 秒**(SoftSPI 151KB/s,固件限制,详见下):**不要设计逐帧动画/滚动/秒级动效**;刷新策略是"内容变化才重绘"(时钟每分钟变一次)
- 字体为预生成抗锯齿字形(4-bit alpha)。当前档位见 `makefont.py`:96/64/56 只含数字和符号,中文在 24/18/16。新增字号或汉字时,在 PC 上改字符集后运行 `makefont.py` 重新生成 `font.py`
- 可用色见 `ui.py` 顶部调色板(RGB565),可任意增删
- 屏幕常亮(背光不可调,硬件接死)

## 硬件/固件说明(非界面相关,可跳过)

- ESP32-S3 N16R8,固件 MicroPython **SPIRAM_OCT v1.28.0**(8MB PSRAM)
- 该固件变体的硬件 SPI(2) 有崩溃 bug(1.26~preview 全系实测),屏走 **SoftSPI 2MHz(151KB/s,整屏 ~1s)**
- 屏:2.4 寸 ILI9341 SPI + 触摸(触摸未用)。注意该屏丝印背光脚为 **LED**(非 BL)
- WiFi → NTP(ntp.aliyun.com)→ Open-Meteo 免 key 天气(走 http 省 TLS 内存)

## 部署

```bash
# 固件刷好后(SPIRAM_OCT v1.28.0,0x0):
mpremote connect COM7 cp config.py ui.py font.py ili9341.py aht20.py main.py :/
```

调试套路:板上 `main.py` 先放 `_safe_main.py` 内容,真代码以 `station.py` 手动 `import station` 试跑,稳定后再转正。
